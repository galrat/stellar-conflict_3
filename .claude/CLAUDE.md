# Глобальные правила поведения

## Рабочий процесс
- Перед выполнением задачи составь краткий план (3-7 шагов) и покажи его мне
- Жди моего подтверждения перед началом работы, если задача затрагивает >2 файлов
- Если что-то в задаче непонятно — спроси СРАЗУ, не угадывай
- Сообщай, если задача выходит за рамки того, что ты можешь сделать надёжно

## Работа с файлами
- Читай только файлы, необходимые для конкретной задачи
- Не трогай файлы, не связанные с задачей
- Перед изменением файла — убедись, что понимаешь его назначение
- Не переписывай рабочий код, если задача — только добавить функциональность

## Экономия токенов
- Не объясняй очевидное — делай, а не рассказывай
- Не повторяй содержимое файлов, которые я уже показал
- Используй /clear перед новой несвязанной задачей
- Следи за /cost — при >20k токенов предупреди меня

## Ответы
- Отвечай кратко. Код — без лишних комментариев, если я не просил
- Если нашёл проблему за пределами задачи — сообщи, но не исправляй без разрешения
- При ошибке: объясни причину в 1-2 предложениях, предложи решение
